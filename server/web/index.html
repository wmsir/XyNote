Creator Guide · 共创与设计指南

模板中心的模板如何设计？插件如何制作？

不需要手写复杂配置文件——直接用小悦笔记搭好样板页就能一键生成标准模板，也可以按照下方规范编写精细主题与 CSS 插件。

STEP 01 · 设计骨架

区分「页面模板」与「多维表格模板」

  • 文档模板 (doc)：顶部放一条 Callout 说明填写方法，用 H2 划分固定栏位，末尾留出待办清单 Todo 槽位。
  • 数据库模板 (database)：设计好列类型（如 title / status / select / date），选定默认视图（表格 / 看板 / 画廊），再保留 2~3 条示范数据 继承选项配色。
STEP 02 · 收录与打磨

一键存进「我的模板」并随时迭代

  • 在软件内打开 「模板中心」 → 点击左侧 「把当前页面存为模板」。
  • 在右侧栏挑选专属 Emoji 或图标、撰写清晰的名称（如「康奈尔深度读书笔记」）和适用场景描述。
  • 模板还在打磨？修改原样板页后点击 「用当前页面更新模板」 即可无痛覆写版本。
STEP 03 · 导出与共享

导出标准 .json，一键上传到社区市场

  • 点击模板中心 「导出」，自动生成标准的 xynote-templates-v1 规范 .json 文件。
  • 别人下载后在「模板中心 → 导入」即可导入到自己的库中，绝不会覆盖已有模板。
  • 点击下方 「+ 分享我的插件 / 模板」 拖入文件即可发布给全网用户。

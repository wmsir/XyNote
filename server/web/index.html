共创与设计指南

模板中心的模板如何设计？插件如何制作？

你不需要手写复杂配置文件——直接用小悦笔记搭好样板页就能生成标准模板，也可以通过下方 JSON / CSS 规范精细定制。

STEP 01 · 设计骨架

区分「页面模板」与「多维表格模板」

  • 文档模板 (doc)：顶部放一条 Callout 说明用途或填写日期，再用 H2 拆出固定结构，末尾留几行空 Todo 待办槽位，每次新建时直接填空。
  • 数据库模板 (database)：先设计好列（如标题、状态 status、优先级 select、日期），切到最适合的默认视图（表格 / 看板 / 画廊），再保留 2~3 条示范数据，这样新建页面会自动继承整套视图和选项颜色。
STEP 02 · 存入并完善元信息

一键收进「我的模板」并随时迭代

  • 在软件顶部或侧栏打开 「模板中心」 → 点击左侧 「把当前页面存为模板」。
  • 在右侧详情栏更换 Emoji 或 SVG 图标、填写清晰的名称（如「周报复盘」或「Bug 追踪看板」）和适用场景描述。
  • 模板还在打磨？改完原页面后点 「用当前页面更新模板」 就能无痛覆盖内容。
STEP 03 · 导出与分享到市场

打包成 .json，别人点击即可导入

  • 在模板中心点击右上角 「导出全部」（或单个模板旁的「导出」），软件会生成标准 xynote-templates-v1 格式的 .json 文件。
  • 其他用户下载该文件后，在软件「模板中心 → 导入」选择文件即可使用，不会覆盖已有模板。
  • 欢迎点击下方 「+ 分享我的插件 / 模板」 把你的好设计传到社区市场！

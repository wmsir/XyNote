# 小悦 · 轻量知识笔记 (XyNote) v0.3.5

**官方网站**：[https://fwpt.cn/](https://fwpt.cn/) · **官方联系与技术支持**：`admin@fwpt.cn`

> **品牌释义**
> - **中文名「小悦」**（对外全称 **「小悦 · 轻量知识笔记」** / **「小悦笔记」**，日常简称 **「小悦」**）：寓意 **“悦享服务、愉悦记录”**，天然带有服务平台的亲和力与流畅感，告别传统工具软件的冰冷感。
> - **英文名「XyNote」**：简洁 6 字母，**`Xy`** 既对应 **XiaoYue** 首字母，又像坐标系的 **X-Y 轴**，暗合软件的**块级结构与多维表格**特性。

本地优先、绿色便携、融合 **块级多维数据库**、**无缝 Markdown + Mermaid 双模编辑** 与 **自定义主题工坊 & 全量可配置快捷键引擎** 的桌面端知识库，基于 **Rust + Tauri v2 + SQLite (WAL + FTS5)** 与 **React 18 + TypeScript + Vite** 构建，支持 **Windows** 与 **macOS** 双端编译。

## 核心特性

- **全量交互式快捷键配置引擎 (`51` 项全覆盖 + 冲突检测 + 导入导出)**：
  - 默认快捷键与主流 Markdown 编辑器保持一致（`Ctrl+0..3` 段落/标题、`Ctrl+Shift+K` 代码块、`Ctrl+Shift+M` 数学公式、`Ctrl+T` 表格、`Ctrl+/` 源码切换、`F8` 专注、`F9` 打字机、`F11` 禅模式等）。
  - 支持全部 **18 种块级转换**、**块操作与 8 种块背景色**、**行内格式化** 以及 **全局视图动作** 的按键实时录制、一键冲突覆盖/互换与 `.json` 方案导入导出。
- **自定义主题工坊与可分享样式插件生态 (`data\plugins\{themes,snippets}`)**：
  - 内置 **5 套精选主题插件**（`GitHub 经典技术白`、`Dracula 暗夜极客紫`、`Nord 极地冰川蓝`、`墨韵书卷`、`清风豆沙护眼绿`）与 **5 款可自由叠加的 CSS 样式增强插件**（`多彩分级标题侧边条`、`学术文档自动编号`、`点阵网格信纸`、`Mac 三色代码块`、`高密度斑马纹表格`）。
  - 内置 **可视化自定义主题工坊 (Visual Theme Builder)** 与在线 CSS 插件编辑器，支持导入/导出分享独立的 `.xynote-theme.json` 与 `.css` 插件文件（可直接拖入窗口安装）。
- **100% 自适应窗口宽度画布 & 960px 居中阅读版心双模切换**：
  - 默认开启 **自适应窗口宽度**，在大屏显示器上铺满工作区视口，同时支持一键切换 **960px 居中阅读版心**。
- **原生 Mermaid v11 图表块实时渲染与矢量 SVG 导出**：
  - 支持 `flowchart`、`sequenceDiagram`、`classDiagram`、`stateDiagram`、`erDiagram`、`gantt`、`pie`、`mindmap`、`timeline` 等主流图表，提供 **预览 / 分栏 / 源码** 三态切换、缩放与全屏放大预览，以及原生对话框一键 **导出 SVG**。
- **富文本多行 GFM 表格与全协议链接 (`file:///` / Web)**：
  - 表格单元格支持自适应多行折行、`<br/>` 换行、行内加粗/代码/链接及左中右列对齐无损往返；支持 `file:///...` 本地文件与目录链接一键在系统文件管理器中打开。
- **绿色便携存储与免重启热迁移**：
  - Windows 默认在软件同级目录初始化 `xynote-config.json` 与 `data\`（含 `xynote.db`、`pages\` 实时 `.md` 镜像、`assets\`、`plugins\` 与 `backups\`）；macOS `.app` 自动安全存储于应用数据目录，支持一键迁移数据目录。（从旧版本升级时，`notion-config.json`、`notion_desktop.db`、`.notion-theme.json` 等旧文件名会在启动时自动改为新名字。）
- **侧栏多文件夹树（磁盘 Markdown 直接编辑）**：
  - 侧栏「文件夹」可同时打开多个磁盘文件夹，按树形结构逐层浏览子文件夹与 `.md` / `.markdown` / `.txt` 笔记，点击即编辑、保存直接写回原文件。
  - 右键支持新建笔记、新建文件夹、重命名（`F2`）、刷新、在文件管理器中显示、复制路径；从侧栏移除文件夹不会删除任何文件。
  - 拖拽即可在文件夹之间移动笔记；删除会移到系统回收站；`Ctrl + K` 同时搜索工作区页面和文件夹里的笔记。
  - 自动监听磁盘变化：在其他程序里新建、改名或修改的文件会实时出现；正在编辑的文件被别处改过时不会互相覆盖，可选择载入、覆盖或另存。
  - 粘贴到磁盘笔记里的图片保存在笔记旁的 `assets/` 目录，Markdown 中写相对路径，换电脑或用其他编辑器打开也能显示。
- **无缝三视图与磁盘 `.md` 直编模式**：
  - **三视图零延迟切换 (`Ctrl + /` / `Ctrl + Shift + /`)**：支持 **所见即所得 (WYSIWYG)**、**源码模式 (Source Code)** 与 **左右分屏实时预览 (Split)** 无损互转，以及 `Ctrl + O` 独立 `.md` 文件直编。

## 同步

默认只保存在本机，完全离线可用。需要多台设备使用时，在 `设置 → 同步` 中选一种方式：

| 方式 | 适合 |
|---|---|
| 仅本地 | 单台电脑、完全离线 |
| 网盘文件夹 | 坚果云、OneDrive、iCloud 等同步盘：选其中一个文件夹，由网盘负责传输 |
| WebDAV | 坚果云、Nextcloud、群晖等（坚果云请使用「应用密码」） |
| 自建服务器 | 自己部署 [`server/`](server/README.md)，支持 Docker |

- 按页面合并：两台设备改了不同的笔记会自动合并；同时改了同一篇时，较新的一份保留在原处，另一份保存为「冲突副本」，不会丢内容。
- 可选端到端加密（AES-256-GCM，密钥由加密密码经 Argon2id 派生）：网盘或服务器只能看到密文；各设备需填写相同的加密密码，忘记无法找回。
- 自动同步：启动时、编辑停止约半分钟后，以及按设置的间隔（默认 5 分钟）。
- 侧栏「文件夹」里的磁盘 Markdown 文件不经过这套同步；把文件夹放在网盘里即可。

## 开发与构建

```bash
# 安装前端依赖
npm install

# 启动前端开发服务器 (http://localhost:1420)
npm run dev

# 启动 Tauri v2 桌面端开发模式
npm run tauri dev

# 前端严格类型检查与生产构建
npm run build

# 打包当前平台桌面端可执行程序与安装包
npm run tauri build
```
